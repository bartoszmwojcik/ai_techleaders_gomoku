# Komponenty

Katalog wszystkich komponentów z małym działającym podglądem, grupą, jednym zdaniem i linkiem do dokumentacji. Wybór komponentu do zadania: [Jak wybrać komponent](?path=/docs/design-system-jak-wybrać-komponent--docs). Czego jeszcze nie ma: [Czego brakuje](?path=/docs/design-system-czego-brakuje--docs).

## Prymitywy

### Przycisk

Wykonuje jedną akcję na stronie. [Dokumentacja](?path=/docs/prymitywy-przycisk--docs), import `@gomoku/ui/game/button`.

<Unstyled>
  <div className="my-stack max-w-xl rounded-base border border-border-default bg-surface-page p-4 text-text-primary">
    <Button>Załóż konto</Button>
  </div>
</Unstyled>

### Link tekstowy

Prowadzi na inną stronę lub w inne miejsce. [Dokumentacja](?path=/docs/prymitywy-link-tekstowy--docs), import `@gomoku/ui/game/text-link`.

<Unstyled>
  <div className="my-stack max-w-xl rounded-base border border-border-default bg-surface-page p-4 text-text-primary">
    <TextLink href="#jak-to-dziala">Jak to działa</TextLink>
  </div>
</Unstyled>

### Pole tekstowe

Jednowierszowy wpis: e-mail, kod, nazwa gracza. [Dokumentacja](?path=/docs/prymitywy-pole-tekstowe--docs), import `@gomoku/ui/game/text-input`.

<Unstyled>
  <div className="my-stack max-w-xl rounded-base border border-border-default bg-surface-page p-4 text-text-primary">
    <TextInput aria-label="Kod zaproszenia" placeholder="ABCD-EFGH" />
  </div>
</Unstyled>

### Pole formularza

Daje polu etykietę, podpowiedź, błąd i znacznik wymaganego. [Dokumentacja](?path=/docs/prymitywy-pole-formularza--docs), import `@gomoku/ui/game/field`.

<Unstyled>
  <div className="my-stack max-w-xl rounded-base border border-border-default bg-surface-page p-4 text-text-primary">
    <Field label="Kod zaproszenia" hint="Wielkość liter nie ma znaczenia.">{(control) => <TextInput {...control} autoComplete="off" />}</Field>
  </div>
</Unstyled>

### Pole wyboru

Potwierdzenie tak/nie, np. zgoda przed usunięciem konta. [Dokumentacja](?path=/docs/prymitywy-pole-wyboru--docs), import `@gomoku/ui/game/checkbox`.

<Unstyled>
  <div className="my-stack max-w-xl rounded-base border border-border-default bg-surface-page p-4 text-text-primary">

</Unstyled>
