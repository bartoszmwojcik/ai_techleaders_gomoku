# Stan zależny od uprawnień

Wzorzec dla ekranów, które wyglądają inaczej dla niezalogowanego, gracza z niepotwierdzonym e-mailem, gracza z potwierdzonym e-mailem i gościa (BR-22, BR-23, D-23).

<Canvas of={Stories.EmailNiepotwierdzonyAkcjeZablokowaneZPowodem} />

## Kiedy używać

- Każdy ekran z akcjami zależnymi od konta: strona główna, lobby, zaproszenie, partia.

## Zasady

1. **Akcja niedostępna jest zablokowana z powodem obok**, nie ukryta bez śladu: „Potwierdź e-mail, aby tworzyć partie i wchodzić do lobby.” Źródło: BR-23, prompt systemu.
2. **Przy niepotwierdzonym e-mailu baner prowadzi do rozwiązania** ([Baner potwierdzenia e-maila](?path=/docs/produkt-konta-baner-potwierdzenia-e-maila--docs)) i zaproszony może zagrać jako gość. Źródło: BR-23.
3. **Niezalogowany widzi jedną główną akcję** („Załóż konto”) i drogę do logowania w nagłówku (R02.1).
4. **Gość nie widzi lobby ani historii** i ma trwałe ostrzeżenie przy partii. Źródło: BR-22.
5. **Serwer jest strażnikiem:** interfejs tylko wyjaśnia; każda zablokowana akcja jest też odrzucana po stronie serwera.
