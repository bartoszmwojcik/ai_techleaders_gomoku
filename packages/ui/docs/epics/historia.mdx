# Epik E04: Historia partii

Lista zakończonych partii gracza: przeciwnik, wynik, data, sposób zakończenia. Źródła: `.ai/specs/product-brief.md` (BR-17, BR-24, D-04), zgłoszenie #27.

## Przepływ

1. Gracz otwiera historię.
2. Widzi tylko własne, zakończone partie; przeciwnik, który usunął konto, to „Usunięty gracz” (BR-17), gość to „{nick} (gość)” (BR-24, BR-29).
