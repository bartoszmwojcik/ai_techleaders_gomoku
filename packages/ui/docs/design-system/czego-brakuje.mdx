## Czego jeszcze nie ma w systemie

| Brak | Dlaczego nie ma | Co użyć zamiast |
|---|---|---|
| select, radio, przełącznik, pole wielowierszowe | żaden ekran w specyfikacjach ich nie potrzebuje | pole tekstowe, pole wyboru |
| menu akcji, popover, podpowiedź (tooltip) | j.w.; podpowiedź nie może nieść informacji niezbędnej do działania | tekst obok elementu, kilka przycisków obok siebie |
| zakładki, panel boczny, awatar | j.w. | osobne strony |
| toast | błąd wymagający działania nie jest toastem; specyfikacje używają `role="status"` | Alert |
| link „przejdź do treści” | nie było w specyfikacjach; do dodania z pierwszą stroną gry | brak |
| stan „wciśnięty” linku tekstowego | brak decyzji | brak |
| nagłówek ekranu partii bez pasków | zdecydowano: zwykły nagłówek (etap 3) | Nagłówek strony |
| filtry i wyszukiwanie list | backlog ich nie ma | lista bez filtrów |
| odtwarzanie partii ruch po ruchu | poza zakresem (#27) | |
| tabela z kolumnami | na telefonie się nie mieści | lista |
| tłumaczenia (polski i angielski, kolejne języki) | osobny temat; komponenty mają teksty przez propsy (Q3) | |
| ruch planszy (stawianie kamienia, reakcja na ruch przeciwnika) | brak referencji | bez animacji |
| pola planszy na wąskim telefonie mają ok. 17 px | WCAG 2.5.8 wymaga 24 px; wyjątek ze specyfikacji, złagodzony dwoma krokami | dwa kroki: zaznacz, potem „Postaw kamień” |

## Do uzupełnienia po teście agentem

Test agentem (etap 5) pokaże miejsca, w których agent budujący nowy ekran musiał zgadywać. Każde takie miejsce trafi do dokumentacji albo tutaj.
