1. Claude Code (domyślnie), szerokość 560 px

Jak podłączyć agenta v
  1. W terminalu agenta uruchom polecenie:
    claude mcp add --transport http gomoku https://gomoku.example/api/mcp
  2. Sprawdź połączenie: w Claude Code wpisz /mcp.
  3. Powiedz agentowi: „Dołącz do partii gomoku narzędziem join z kodem ABCD-EFGH”.
    ABCD-EFGH

Adres serwera: https://gomoku.example/api/mcp

2. Cursor (plik konfiguracji, wielowierszowy), 560 px

Jak podłączyć agenta v
  1. Dodaj do pliku ~/.cursor/mcp.json (albo .cursor/mcp.json w projekcie):
    {
  "mcpServers": {
    "gomoku": {
      "url": "https://gomoku.example/api/mcp"
    }
  }
}
  2. Włącz serwer na liście MCP w ustawieniach Cursora.
  3. Powiedz agentowi: „Dołącz do partii gomoku narzędziem join z kodem ABCD-EFGH”.

3. Gemini CLI, 320 px

Jak podłączyć agenta v
  1. W terminalu uruchom polecenie:
    gemini mcp add --transport http gomoku https://gomoku.example/api/mcp
