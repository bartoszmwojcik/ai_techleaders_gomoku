# Status tury

## 1. Do czego służy

Mówi słowami, czyj jest teraz ruch, żeby gracz nie musiał tego odgadywać z planszy.

<Canvas of={Stories.Playground} />

## 2. Kiedy używać

- **Nad planszą w trakcie partii:** „Twój ruch (czarne)”, „Ruch przeciwnika” (game-moves).
- **Przed startem:** „Czekamy, aż przeciwnik otworzy partię” (game-invitations, Q20).

## 3. Kiedy nie używać

- **Wynik partii:** [Baner wyniku](?path=/docs/produkt-partia-baner-wyniku--docs).
- **Czas:** [Zegar gracza](?path=/docs/produkt-partia-zegar-gracza--docs).
- **Błąd:** [Stan błędu](?path=/docs/prymitywy-stan-błędu--docs) lub Alert.

## 4. Anatomia

1. **Kamień w kolorze gracza** (opcjonalny, dekoracyjny).
2. **Słowa** (wymagane): kto się rusza i jakim kolorem gra.

## 5. Warianty

Brak wariantów wyglądu; zmienia się tekst i kolor przypomnienia (czarny lub biały kamień).

<Canvas of={Stories.Warianty} />

## 6. Stany

Twoja tura, tura przeciwnika, oczekiwanie. Najechania, fokusu, wciśnięcia, zablokowania i ładowania nie ma (nie dotyczy, to tekst).

## 7. Zachowanie i dostępność

- **Rola:** `role="status"`: zmiana tury jest ogłaszana grzecznie. Źródło: game-moves, WCAG 4.1.3.
- **Kolor nie jest jedynym nośnikiem:** własny kolor oznaczony tekstem („czarne”, „białe”), kamień jest dekoracją (WCAG 1.4.1).
- **Klawiatura:** nie przyjmuje fokusu.

## 8. Treść

- **Formuła:** „Twój ruch (czarne)”, „Ruch przeciwnika”; bez wykrzykników i bez imienia przeciwnika, jeśli to nie pomaga.
- Komponent nie ma wbudowanych tekstów.

## 9. Responsywność

Tekst zawija się; kamień zostaje przy pierwszej linii.

<Canvas of={Stories.DlugaTrescNaWaskimEkranie} />

## 11. Kod

```tsx
import { TurnStatus } from "@gomoku/ui/game/turn-status";

<TurnStatus color={myColor}>{yourTurn ? "Twój ruch (czarne)" : "Ruch przeciwnika"}</TurnStatus>;
```

## 12. Dobrze i źle

**Dobrze:** słowa niosą informację, kamień tylko ją przypomina. **Źle:** sam kolorowy kamień bez słów, komunikat o turze w toaście (znika, a stan trwa).

<Canvas of={Stories.OgloszenieGrzeczne} />

## 13. Powiązane

- **Mylony z:** Zegarem gracza (czas) i Banerem wyniku (koniec).
- **Występuje we wzorcach:** widok szczegółów (partia).
