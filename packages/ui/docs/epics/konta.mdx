# Epik E01: Konta użytkowników

Rejestracja, logowanie, potwierdzenie e-maila, reset i zmiana hasła, usunięcie konta. Źródła: `.ai/specs/product-brief.md` (BR-14…BR-25, D-12…D-18), `.ai/specs/2026-10-24-account-registration.md`, `login-logout.md`, `email-verification.md`, `password-reset.md`, `password-change.md`, `account-deletion.md`.

## Przepływ

1. Gość zakłada konto (`/register`) i jest od razu zalogowany.
2. Gra od razu (BR-26). Potwierdzenie e-maila (`/verify-email`) jest osobną czynnością; zamykalny baner na `/` i `/account` tłumaczy, po co (reset hasła tylko po potwierdzeniu).
3. Loguje się (`/login`); zapomniane hasło ustawia przez e-mail (`/forgot-password`, `/reset-password`).
4. Na `/account` zmienia hasło albo usuwa konto (nie w trakcie partii, BR-21).

## Co jeszcze zostaje w produkcie

- Strony i logika to praca implementacyjna (#19, #20, #34, #35, #36, #37): design system dostarcza komponenty, stany i zasady.
- Zmiana e-maila i nazwy gracza jest później (E05, D-18).
- Strona o przetwarzaniu danych powstanie przed udostępnieniem gry osobom z zewnątrz (D-22).
- Stany odpowiedzi API formularza pokazuje wzorzec [Formularz](?path=/docs/wzorce-formularz--docs).
