# Lista

Wzorzec dla list gracza: lobby i historia partii. Filtrów nie ma, bo backlog ich nie przewiduje (decyzja właściciela); gdy się pojawią, wzorzec zostanie rozszerzony o licznik wyników, aktywne filtry i stan „brak wyników dla filtrów”.

<Canvas of={Stories.LobbyDuzoDanych} />

## Kiedy używać

- Lista graczy szukających gry (E03) i lista zakończonych partii (E04).
- Nie używaj jej dla pojedynczego obiektu (wzorzec Widok szczegółów).

## Zasady

1. **Lista ma nazwę dla czytnika** i jest prawdziwą listą (`ul`/`li`).
2. **Pięć rodzajów stanu ma osobny wygląd:** ładowanie ([Szkielet](?path=/docs/prymitywy-szkielet-ładowania--docs) z jednym opisem), pusto ([Pusty stan](?path=/docs/prymitywy-pusty-stan--docs)), błąd ([Stan błędu](?path=/docs/prymitywy-stan-błędu--docs) z ponowieniem), dane częściowe i dużo danych.
3. **Pusto ma powód i następny krok:** „Nie rozegrałeś jeszcze żadnej partii” z akcją „Utwórz zaproszenie”. Źródło: prompt systemu, A05.
4. **Błąd wymagający działania nie jest chwilowym komunikatem:** zostaje na ekranie z przyciskiem „Spróbuj ponownie”.
5. **Dane częściowe nie psują układu:** brak opcjonalnych pól (np. „od kiedy szuka”) po prostu ich nie pokazuje.
6. **Długie nazwy zawijają się** w dowolnym miejscu; wiersz nigdy nie wychodzi poza ekran 320 px.
7. **Lobby pokazuje czas wygaśnięcia przy każdym wierszu** (A05); historia pokazuje wynik słowem i ikoną.
